目标：按已确认多页预览实现可用本地站点，后续以 Vercel + Supabase 免费方案上线。
约束：全部网站文件位于本目录；不修改原 Python 应用；只配置本地模式，不发布云端。

1. 输入与存储：先编写姓名、电话邮箱、选填内容与隐私确认回归；实现本地SQLite和服务端Supabase适配。
2. 页面：实现共享大导航和产品Logo、多页入口、真实截图放大、流程切换、FAQ、反馈表单和私有管理。
3. 下载：准备完整原版程序ZIP及SHA256；本地流式下载，云端使用DOWNLOAD_URL。

5. 云端边界：schema.sql仅作为待执行迁移。实际Supabase RLS与Auth、Vercel部署和免费额度须上线时另行验证。
